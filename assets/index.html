外观

            
终端和界面的显示方式。字体随应用分发，不依赖系统安装。

          

          

            

              

                语言
                界面语言。自动 = 跟随 Windows。
              

              

                
              

            

            

              

                界面风格

                主题

行为

            
新建格子时预选哪个 Agent；关窗和结束 agent 都是会带走正在运行的东西的动作，默认先问一句。

          

          

            

              

                默认 Agent
                点 + 新建格子时预选谁。自动 = 优先挑有状态能力的已安装 Agent。
              

              

                
                
              

            

            

              

                新建格快捷键
                按下后直接在当前文件夹用上次的 Agent 新开一格，不弹选择；没有记忆时用上面的默认 Agent。留空 = 关闭。
              

              

                
                
              

            

            

              

                关闭窗口前确认
                点窗口右上角的 × 时先问一句。确认后所有正在跑的 agent 会随窗口结束。
              

              

                
                
              

            

            

              

                结束 agent 前确认
                「结束这个 agent」会删掉它的座位记录（磁盘上的会话文件不动），动手前先问一句。
              

              

                
                
              

            

            

              

                启动时打开
                下次打开 Perch 先落在哪一页。这一次不会跳。
