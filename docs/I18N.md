# 界面语言（i18n）

Perch 的界面语言是 **auto / en / zh**，落盘在 `%APPDATA%\Perch\settings.json` 的
`language` 字段。设置页切换后**不重启**：静态节点和 JS 现画的区域都会就地重画。

范围只包括 **Perch 自己的界面文案**。终端内容、agent 的输出、模型名/路径都不在这里；
网关引擎没有可加载的界面，它的语言设置也不需要出现。

## 运行时

全部在 `assets/js/01-i18n.js`：

| 名字 | 用途 |
|---|---|
| `PERCH_I18N.en` / `.zh` | 两份字典。key 是稳定标识，不是英文原文 |
| `t(key, vars)` | 取当前语言；缺 key 依次回退 en → zh → key；`{name}` 用 vars 替换 |
| `tCount(base, n, vars)` | 带数量的句子；`n === 1` 且当前字典有 `base + "One"` 时用单数变体（只有英文需要） |
| `tMsg(code, params, fallback)` | 后端消息：按 `msg.<code>` 渲染，查不到用原文兜底 |
| `msgText(m)` | 一条“可重放的错误”：`{key}` 或 `{code, params, text}` → 当前语言文本 |
| `errMsgOf(m, fallbackKey)` | 把推送里的 `{err, errCode, errParams}` 变成上面的结构 |
| `applyStaticI18n(root)` | 处理带 `data-i18n*` 的静态节点 |
| `setLocale(pref)` | 解析并应用语言；变化时调用 `onLocaleChanged()` |

语言解析：`auto` 看 `navigator.languages`，任何 `zh*` → `zh`，否则 `en`。
`localStorage` 里的 settings 缓存只负责**首帧**，Go 的 `settings` 载荷到达后以 Go 为准。

## 静态 HTML

`assets/index.html` 里不要写死用户可见文案，用属性标记：

```html
<span data-i18n="nav.settings">设置</span>
<span data-i18n-text="settings.language.note">…</span>
<span data-i18n-html="settings.foot.html">…</span>
<button data-i18n-title="files.refresh" data-i18n-aria-label="files.refresh">…</button>
<input data-i18n-placeholder="ac.pick.search">
```

属性里的中文是**兜底**，不是事实源；字典缺 key 时仍能显示。

需要保留子元素（例如说明文字后面的 `<em>`）时，用 `data-i18n-text` 或把文案拆成
多个带 key 的 `<span>`，不要用 `data-i18n` 覆盖整块 `innerHTML`。

## 动态渲染的四条规则

1. **`t` 的名字会被局部变量遮住。** 很多函数有 `const t = activeTab`。这些函数里
   要调用全局翻译时，先把局部变量改名（例如 `tab`），否则运行时是
   “t is not a function”。
2. **增量渲染的签名要算上语言。** 只比较数据的缓存签名（`g1/g2/g3`、
   `askBlockSig`、`permBlockSig`、文件根选项、热力图骨架…）在切语言后不会重画，
   屏上会留下上一门语言。把 `PERCH_LOCALE` 加进签名字符串。
3. **状态里存结构，不存渲染好的句子。** 错误存成 `{key}` 或
   `{code, params, text}`，显示时过一遍 `msgText`。这样切语言只要重画，不需要
   重新请求后端。例子：`CWD_ERR`、`FS.err`、`FV.readErr`、`GW_AGENTS_ERR`、
   `INSTALL.err`。
4. **新的动态区域要在 `onLocaleChanged()` 里重画。** 入口在
   `assets/js/85-settings.js`；目前覆盖导航、左栏、标签头、总览、文件树/预览、
   流水/对话流、群组看板、安装台、新建工作区卡片、设置页、状态栏。新增模块时
   对照这张清单补一行。

## 后端消息：code + params + 原文

Go 侧用户可见的错误不要只发一句话。`internal/uimsg` 定义：

```go
uimsg.New("settings.notDir", "这个目录不存在，或者不是一个文件夹")
uimsg.NewParams("settings.unknownAgent", "不认识这个 agent："+id,
    map[string]string{"agent": id})
uimsg.Wrap(err, "install.startFailed", "起不了安装进程："+err.Error(),
    map[string]string{"err": err.Error()})
```

- `Error()` / `Text` 始终是**原文**：日志、旧前端、以及字典里没有的 code 都用它。
- `uimsg.Fields(m, err)` 把 `err`、`errCode`、`errParams` 并进一份推送。
- 前端用 `tMsg(code, params, fallback)` 或 `msgText(...)` 渲染。

对应字典 key 是 `msg.<code>`。新增一个 code 时，**两份字典都要加**，然后运行
`node scripts/i18n-check.mjs`；它会扫描 `uimsg.New/NewParams/Wrap`、`setSnapErr`、
`MsgCode:`、`failed(...)`、`updateReasonErr(...)`，发现缺 key 就失败。

## 与网关引擎的语言

网关引擎只作为后台进程使用，Perch **不加载、不反代它的 Web UI**，所以 Perch
的语言设置不需要写进引擎的 `settings.lang`。前端看到的供应商/Agent/用量文案
全部由 Perch 的 `01-i18n.js` 和 `msg.*` 渲染；引擎返回的原始英文错误不进 DOM。

## 加一门语言

当前只支持 en / zh。要加 `ja`（举例）：

1. `01-i18n.js` 加 `ja` 字典（先复制 en，再逐条翻译）；扩展
   `perchResolveLocale` 和设置页的 `<select>`。
2. `internal/settings` 的语言校验同步。
3. 把 `data-i18n` 的静态兜底、动态 `t()` 文本走一遍；补 `onLocaleChanged` 清单。
4. `node scripts/i18n-check.mjs` 必须通过；再做一次双语截图走查。

英文单复数用 `base + "One"`；中文和其他语言不需要 `One` 键。

## 验证

```powershell
node scripts/i18n-check.mjs     # 缺 key / 单边 key / msg code / 占位符
Get-ChildItem assets/js -Filter *.js | ForEach-Object { node --check $_.FullName }
go test ./...
```

CI 跑同样的三组（`.github/workflows/ci.yml`）。

手工走查至少覆盖：总览（Agent 工作台、行内详情、网关用量卡）、工作区（含群组看板）、
设置、文件树与预览、新建工作区、网关页（供应商目录、编辑器 sheet）；每页在 en/zh
各看一遍，切语言时不重启、不留下上一门语言。

## 已知边界

- 终端里 PTY 的提示由 Go 直接写字节：启动失败（`Start failed / 启动失败`）和
  进程退出（`Process exited / 进程已退出`）。显式 en/zh 跟设置走，`auto` 时双语
  —— 后端看不到 `navigator.languages`。措辞在组合根 `cmd/perch/main.go`
  （`termWord` / `termMsg`）和 `stream.Callbacks.ExitNotice`，`stream` 不认识设置。
- 目前只有 en/zh；zh-TW/ja/de 的系统上 `auto` 会回退到 en。增加语言时先扩展
  `perchResolveLocale`、设置页的 `<select>` 和 `internal/settings` 的校验。
