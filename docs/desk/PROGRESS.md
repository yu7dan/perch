# 台面形态（0.1.1）· 进度与验收

> 每一轮开工先读这份文件；做完一项就打勾、写下自己拿的主意。
> 标准答案：`spec/desk/`（定稿模拟，`node spec/desk/serve.mjs`，地址加 `#ch=<章>` 只放一章）。

## 规矩（用户定的）

- **一切以对齐模拟为准**。旧产品该摒弃的摒弃、该移除的移除、该改进的改进；不和旧界面强行关联。
- 分支 `feat/desk`：可以推到 GitHub 备份；**不合 main、不发版**，直到用户最终验收 → 整套发版为**正式版 0.1.1**。
- 每做完一个模块给用户一条短消息；四个里程碑各录一段真产品全屏导览给用户看。
- 模拟没定义的：照模拟的思路 + 现有产品/记忆自己拿主意，记在下面「决定」里；真要用户定的，先跳过、留言，全做完还没回才停。
- 测试实例隔离（`_tools/termtest-run`），agent 用便宜模型；**不碰用户在用的 Perch、agent 配置**。

## 验收流水线

1. 构建测试实例：`powershell -File D:\AIAgents\_tools\termtest-run\build.ps1`
2. 启动（带调试端口 9333，强制隔离）：`powershell -File D:\AIAgents\_tools\termtest-run\launch-cdp.ps1`
   - ⚠️ 这个脚本**只能是 ASCII**：PS 5.1 读无 BOM 的中文会乱，曾经把 APPDATA 覆盖弄丢、让测试实例跑在用户真数据上（2026-11-08，已核对无损失）。
3. 驱动 / 截图：`node tools/deskcheck/cdp.mjs eval|shot|click|dbl|drag|type|key …`（PERCH_PAGE=orb 连悬浮按钮窗口）；里程碑导览：`node tools/deskcheck/tour.mjs tools/deskcheck/tours/m1.mjs out.mp4`
4. 对照：同一章在模拟里跑到同一步截图，并排比；行为用 eval 读状态断言。
5. 前端快速迭代时可以先「真前端 + 模拟后端」无头跑，模块收尾必须在真程序上过一遍。

## 决定（我自己拿的主意）

- 格子身体在 0.1.1 先放真终端：Agent 界面用户说过以后单独设计；格子外框、格头、状态全部照模拟。
- 保留界面语言（中/英）：模拟里没有语言项，但产品是公开的、已有英文；放在 设置 › 通用。

- 2026-11-08 M1：旧外壳整块删除；终端 / 通道 / 实时读数三套引擎留下，搬进 02-util、15-term-ime、21-state、22-live；台面在 30-desk-core（照模拟逐段移植）。
- 格子里的终端底色透明，透出格子那层玻璃；终端在台面上只有暗色一套（台面没有浅色主题）。
- Esc 在终端里是 agent 自己的键（Claude 靠它打断），台面一个都不拦；点到格子以外，键盘就从终端里退出来，Esc 回到台面手里。聚焦（双击格头）时格头多一颗「回去」按钮。
- 关一格 = 关掉运行、记录留着（close-is-not-delete）；空格子里列出这个项目里上次关掉的，一键接回。格子里的 agent 自己退出了，格子上给「接着来」（同一个 paneId 接回那条会话）。
- 铃铛计数 = 「需要你」里的未读那一组（提问 / 批权限 / 登录门 + 跑完一轮没看），不只模拟里的「提问」—— 和旧产品的需要你同一个判据。
- 布局按 paneId 记住每一格坐的是谁；重开时 Go 的冷恢复清单说接回哪几格，它们回到原座位，没座位的另摆一块；上次关掉的座位变回空格。从没说过话的空 agent 本来就不恢复（Go 的老规矩）。
- 退出 Perch：Alt+F4 / 任务栏关闭 → 台面确认框（设置里关了确认就直接退）。设置 › 关于 里再放一个「退出 Perch」（M2）。
- 没装的 agent：安装器给不出百分比，图标里的液面按时间涨、停在九成，装完才灌满（说的是「还在装」，不冒充精确进度）；不能代装的提示去官网装。
- 收起期间主窗口藏着但页面照跑（实测每秒推一次按钮状态）；Go 不转发前端事件（转发器自己转自己，曾把进程内存耗尽）。
- 台面上的字目前只有中文；「界面语言」那条决定照旧，英文在 M2 做设置时一次性补（整份对照表）。
- M2：选文件夹窗口走 Go 新加的 dir.browse（任意位置只列子文件夹名，不读文件；隐藏 / 系统文件夹不列）；窗口底下留一个「Windows 自带的选文件夹窗口」出口。
- 冷启动时会话库要扫几十秒：项目名单改成跟着冷恢复清单一起先到（不带统计），台面一起来就能挑项目；总览在会话库没到时写「正在读会话库…」。
- 文件块的「改过的行标绿」= 最近那一次改动（trace.diff）在新文件里落的行号；「全部」那棵树每 8 秒在后台重读一次（agent 在写盘）。
- 设置里四样由 Go 落实：全局快捷键（呼出/收起；测试实例不注册，免得抢正在用电脑的人的键）、开机启动（HKCU Run；测试实例用单独的项名）、启动时恢复台面、铺在哪块显示器。退出 Perch 前确认 = 设置里原来那条「关窗确认」。
- 关掉主窗口时一并关掉悬浮按钮窗口，否则 Wails 认为还有窗口、进程不退。
- 英文（界面语言）放到最后一轮一次做：台面的字还会在 M3/M4 里加，做两遍不值。
- M3 模型：格子换模型「不用重启」靠 Go 新加的本机转发层（internal/relay）：选了提供商的格子连 127.0.0.1 上这一格专用的地址（路径里带随机令牌），转发层带真 key 转给这一格现在选的提供商并改写模型名；换提供商之后去掉历史里的 thinking 块（上一家的签名）。用两个假提供商（tools/deskcheck/mockprov.mjs）真机验过：同一个 Claude 进程，下一句话就换到了另一家。
- 牵涉 agent 自己的登录（订阅 / 自带账号）的切换不走转发层（不碰用户的登录态）：同一个 paneId 接回原会话重开这一格，提示里说清楚。干活中的格子先记着（格头「→ 新模型」），这一轮跑完再换。
- 格头的模型按钮说的是这一格**起的时候**用的那套（设置里之后改默认不影响它）；自己选过的跟着布局记住，重开 / 接回还是它。
- 「检测并保存」= provider.save + Go 顺手测一次（拿模型列表）；提示里写 Anthropic / OpenAI 接口有没有、几个模型。预设清单用 magpie 的那份 + 模拟里的零词元。
