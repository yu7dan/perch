# 台面形态（0.1.1）· 进度与验收

> 每一轮开工先读这份文件；做完一项就打勾、写下自己拿的主意。
> 标准答案：`spec/desk/`（定稿模拟，`node spec/desk/serve.mjs`，地址加 `#ch=<章>` 只放一章）。

## 规矩（用户定的）

- **一切以对齐模拟为准**。旧产品该摒弃的摒弃、该移除的移除、该改进的改进；不和旧界面强行关联。
- 分支 `feat/desk`：可以推到 GitHub 备份；**不合 main、不发版**，直到用户最终验收 → 整套发版为**正式版 0.1.1**。
- 每做完一个模块给用户一条短消息；四个里程碑各录一段真产品全屏导览给用户看。
- 模拟没定义的：照模拟的思路 + 现有产品/记忆自己拿主意，记在下面「决定」里；真要用户定的，先跳过、留言，全做完还没回才停。
- 测试实例隔离（`_tools/termtest-run`），agent 用便宜模型；**不碰用户在用的 Perch、agent 配置**。

## 验收流水线

1. 构建测试实例：`powershell -File D:\AIAgents\_tools\termtest-run\build.ps1`
2. 启动（带调试端口 9333，强制隔离）：`powershell -File D:\AIAgents\_tools\termtest-run\launch-cdp.ps1`
   - ⚠️ 这个脚本**只能是 ASCII**：PS 5.1 读无 BOM 的中文会乱，曾经把 APPDATA 覆盖弄丢、让测试实例跑在用户真数据上（2026-11-08，已核对无损失）。
3. 驱动 / 截图：`node tools/deskcheck/cdp.mjs eval "<js>"`、`node tools/deskcheck/cdp.mjs shot <png>`
4. 对照：同一章在模拟里跑到同一步截图，并排比；行为用 eval 读状态断言。
5. 前端快速迭代时可以先「真前端 + 模拟后端」无头跑，模块收尾必须在真程序上过一遍。

## 里程碑与模块

### M1 台面外壳 + Dock + 收起按钮
- [ ] 全屏无边框铺满主屏；背景三种：桌面壁纸（读注册表、壁纸变了跟着换、盖住整个桌面）/ 渐变 / 纯色
- [ ] 旧外壳下线：左两栏、右栏（文件/对话流）、标题栏 chrome、经典模式、旧设置页、旧总览页、旧 Bot Group 页、旧新建卡
- [ ] 块：空白处拖出圈块（太小/重叠拒绝、红框）、选种类（并行 / 单个 / Bot Group / 文件）、挪、八向缩放、块头（标题·副标题·收起·关闭）
- [ ] 块里切格：切分树铺满、边上 + 切格（18px）、拖缝、最小 200×132 拒绝再切、双击标题聚焦 / Esc
- [ ] 格子：头（logo·名字·项目·碰过的文件数·模型·状态点·关闭），身体暂时放真终端（Agent 界面以后单独设计），等你时琥珀边
- [ ] 单格块：块头当格头
- [ ] 不重叠（默认）/ 允许重叠开关（Dock + 设置），点谁谁在前；关掉后已叠的能挪出来
- [ ] 收起成标签：可拖、显示在跑/等你、点开回原位（被占就找空地）、全部收起沿 Dock 排、全部展开
- [ ] Dock：九个按钮 + 分隔 + 把手；能拖到任意位置，贴左右竖排、贴上下横排；贴边时台面让出一条（块挪/收，Dock 走了复原）；浮层从 Dock 旁边长出
- [ ] Agent 托盘：拖到格子边 = 切格、拖到空白 = 新块、拖进 Bot Group = 加 Bot
- [ ] 等你：铃铛计数、点了跳过去（收起的块先展开）
- [ ] 收起 Perch → 悬浮按钮窗口（Perch 标、可拖贴边、在跑光环、等你琥珀 + 计数、新等你冒气泡跳一下、点一下回来）；收起时主窗口隐藏
- [ ] 台面布局保存/恢复（块、切分、标签、Dock 位置）

### M2 项目 / 文件 / 设置 / 总览
- [ ] 项目面板（Dock）：列表、在跑的 agent、打开文件、在这开一个 Agent（找空地 / 没地就圈）、移除（有在跑的先确认）
- [ ] 选文件夹窗口（真磁盘）：选已有的（左侧快捷位置、面包屑、单击选中双击进入）/ 新建（进到哪建在哪、重名/非法字符检查）；默认工作区也用它
- [ ] 「文件」块：项目切换、碰过的（改/新/读 + 谁动的）、全部（树）、预览（改过的行标绿）、窄时列表/预览切换；格子里「碰过的文件数」→ 弹出清单 → 在文件块打开（没有文件块就速览）
- [ ] 设置大面板：通用 / 台面 / 项目 / 模型 / Agents / 关于；即改即生效、会记住
- [ ] 总览面板（Dock）：五个数、热力图（轮次/token）、按模型的 token、在等你 / 开着的 / Bot Group 列表，点一项跳过去；只刷新内容不闪

### M3 模型 / Bot Group / 人设 / 就地下载
- [ ] 提供商：预设、填 key、检测（Anthropic/Chat/Responses）、保存、删除
- [ ] Agents 默认模型 + 推理强度；格子模型随时换（干活中下一轮生效、空闲立即）—— 本机转发层，不重启
- [ ] Bot Group 三步建组（块里）→ 开工；群聊、@、成员详情（在干什么、换模型、单聊、移出）、中途加 Bot、拍板卡、预算条、全部暂停
- [ ] 人设与岗位：建组时每行「人设」、开工后成员详情里改、存模板、写进成员工作副本的岗位说明
- [ ] Agent 就地下载：没装的灰、悬停玻璃下载、点了液体灌满图标；三处入口（空格子、托盘、建组/加 Bot）

### M4 应用启动台
- [ ] 读开始菜单的应用列表 + 搜索 + 网页搜索/网址
- [ ] 网页块：Perch 自己的 WebView2 窗口贴在块上跟着走；浮层打开时让位
- [ ] 桌面应用：能在台面里开就开；不能的提示「目前不支持在产品内打开，可以收起 Perch 后单独打开（收起不影响正在跑的工作）」+「收起 Perch」按钮；收起状态下一律在外面正常打开
